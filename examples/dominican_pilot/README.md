# Culturally Grounded Dominican Spanish Pilot Dataset

**Tracking:** [Issue #3](https://github.com/Luisv8181/weightliftai/issues/3)

## Overview

This dataset comprises 50 curated triads comparing:
1. **Culturally authentic Dominican Spanish expressions:** including idioms, pragmatic markers, regional vocabulary, and syntax.
2. **Matched neutral Spanish controls:** standard Spanish formulations expressing equivalent informational content.
3. **English pragmatic intent references:** translations capturing true communicative and emotional meaning.
4. **English literal translations:** highlighting typical machine translation failure modes.
5. **Negative controls:** cross-concept factual/scientific statements used to establish null baseline distances in representation space.

## Linguistic Principles

- **Pragmatic Grounding:** Evaluates whether models capture conversational nuance, humor, urgency, and indirect requests rather than mere surface lexical matching.
- **Regional Representation:** Includes expressions across Santo Domingo, Cibao, and broader Dominican discourse.
- **Partitioning:** Partitioned into 30 train, 10 validation, and 10 held-out test concepts.
