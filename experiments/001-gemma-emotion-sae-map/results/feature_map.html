A map of emotion features

Each glowing point is one feature. Features whose directions inside the model are similar sit close together. Color shows which emotion the feature fires on most; size shows how specific it is to that emotion.

Positions come from projecting each feature's direction down to 2-D, which loses information: nearby points are similar, but distance is only a rough guide. Click a point to open it on Neuronpedia; click a legend chip to dim the other emotions.
