Watching the model think, word by word

Columns are depths in the model, from early layers (left) to layers near the output (right). Each dot is one sparse-autoencoder feature; it swells and glows when it fires on the current word. Lines join features active on the same word at neighbouring depths. They show co-activation, not proven cause. Tracing true cause needs attribution methods (for example transcoders), which is a later step. Labels are automated descriptions; treat them as hints.
